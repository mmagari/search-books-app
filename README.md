# 📚 Books Search App

Simple web application for searching books using the Open Library API.  
You can browse results, filter by author, and save your favorite books locally.

---

## 🚀 Features

- 🔎 Search books by title or author
- ⚡ Debounced search (live typing)
- 🧑‍💻 Filter results by author
- ❤️ Add/remove books to favorites
- 💾 Favorites saved in localStorage
- 🖼️ Book covers with fallback ("No cover")
- 📱 Responsive layout (mobile + desktop)

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (BEM methodology)
- Vanilla JavaScript (ES6+)
- Open Library API
